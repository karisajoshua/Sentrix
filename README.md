# Sentrix

Geospatial political intelligence and public-project accountability dashboard.

## Stack
React + TypeScript + Vite, MapLibre GL JS, deck.gl, Supabase/PostGIS.

## Development
```bash
npm install
cp .env.example .env
npm run dev
```

The initial release uses clearly labeled illustrative project records and OpenStreetMap map tiles. No example is presented as a verified government project. Configure a production basemap provider and real, verified data before public launch.
